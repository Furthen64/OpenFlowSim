# Task 06: Validation & Test Cases

## Goal
Verify the Rust icoFoam implementation produces results matching OpenFOAM within tolerance.

## Test Cases (in order of difficulty)

### 1. Pipe Flow (analytical)
- Geometry: straight circular/square channel, fully developed
- BCs: fixedValue inlet, zeroGradient outlet, noSlip walls
- Expected: parabolic Poiseuille profile (analytical solution known)
- Validates: laplacian, pressure gradient drive, noSlip, steady convergence
- Run transient until steady; compare final U profile to analytical

### 2. Lid-Driven Cavity (benchmark)
- Geometry: square cavity, lid moving at U_lid
- BCs: fixedValue on lid, noSlip elsewhere, p zeroGradient everywhere
- Expected: primary vortex + secondary corner vortices
- Validate against: OpenFOAM reference run (same mesh, same dt)
- Check: U field L2 error, streamfunction pattern, convergence behavior

### 3. Backward-Facing Step (flow separation)
- Geometry: sudden expansion
- BCs: inlet velocity, outlet pressure, noSlip walls
- Expected: separation bubble, recirculation zone
- Validate against: OpenFOAM reference run
- Check: separation point location, U profiles at stations

## Deliverables
- Test case directories under `icoFoamRust/cases/` with full OpenFOAM input
- Reference data generated by running actual OpenFOAM 14 (store in `icoFoamRust/reference/`)
- Comparison script/reuse of `validation/` crate: element-wise L2 error, max error, field plots
- Tolerance targets: < 1e-5 relative L2 for identical mesh/scheme/dt
